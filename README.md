# MStar TV apps

Downloads for the MStar TV Android apps. The newest files are always on the [latest release](https://github.com/mstafaahmad1999-lgtm/mstar-tv-apps/releases/latest):

- **Phone:** [MStarTV-phone.apk](https://github.com/mstafaahmad1999-lgtm/mstar-tv-apps/releases/latest/download/MStarTV-phone.apk)
- **Android TV:** [MStarTV-TV.apk](https://github.com/mstafaahmad1999-lgtm/mstar-tv-apps/releases/latest/download/MStarTV-TV.apk). On a TV, type `mstar-tv.site/tv.apk` into the Downloader app.

Already have the app? Open Settings in the app and choose **Download latest version**.
